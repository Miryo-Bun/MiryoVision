# MiryoVision

**Freedom through technology. ❤️**

MiryoVision is an open-source image analysis plugin for Claude Code, developed as part of the independent **MiryoLove** project.

The project provides local image inspection and analysis through Python utilities, with the goal of supporting image metadata extraction, visual analysis and optical character recognition (OCR).

### Supported formats

- PNG
- JPG
- JPEG
- WEBP
- BMP
- TIFF

### Features

- Local image file inspection
- Image metadata extraction
- Image format and resolution detection
- Color mode identification
- Image file size reporting
- Visual image analysis through Claude Code
- OCR text extraction (planned)
- Original image files are never modified by the analyzer

### Technology

- Python
- Pillow
- Claude Code Plugin system
